03 / THE INTEGRATION

A real backend decision.
A bounded claim.

ArmorIQ sits in the website’s server-side operation gateway. The agents do not get its key or choose their own principal. This tests mediated operations; it is not a claim that an SDK automatically protects any website.

  1. 01Capture the request

    One requested operation and its exact arguments become a plan.

  2. 02Ask ArmorIQ

    The public SDK checks the call in remote SDK mode.

  3. 03Execute or refuse

    The site executes only after an explicit remote allow.

  4. 04Report and close

    Record the result, complete the plan, and retain receipt status.
